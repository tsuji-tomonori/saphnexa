## 検討・判断

- `packages/db-schema/src/tables.ts` は required table 名だけを扱うため、plan の DB type 共有要件に対して列・主キー・logical type が不足していた。
- 今回は実 DSQL introspection 生成型ではなく、Flyway migration source 由来の static metadata として `table-metadata.ts` を追加した。
- Chat、RAG、realtime、admin artifact、audit/tool invocation に関わる主要 table から typed metadata を追加し、全 table 全列の完全 generated type は別 slice として残した。
